# Platform Evolution Plans Index

This directory records the evolution of the Skill and Agent platform. Source code and executable tests are the authority for current behavior; plan documents retain the decisions, acceptance criteria, and historical rationale that led here.

- [Architecture Hard Reset](architecture-hard-reset/00-analysis.md): implementation is phased. P1, the P2 migration-runner mechanics, and P3-R1 baseline validation are delivered. P3-R2 instrumentation/export tooling is delivered, but its production observation, retention, consumer, rollback, and approval evidence is still pending; P3 destructive execution remains blocked behind those evidence and retirement gates. Its [delivery plan](architecture-hard-reset/01-plan.md), [target specification](architecture-hard-reset/02-spec.md), [design](architecture-hard-reset/03-design.md), [acceptance tests](architecture-hard-reset/04-acceptance-tests.md), [deletion/migration ledger](architecture-hard-reset/05-deletion-and-migration-ledger.md), [todo list](architecture-hard-reset/06-todo.md), [current inventory](architecture-hard-reset/07-p3-inventory.md), [P3 reconciliation](architecture-hard-reset/08-p3-reconciliation-44f9de4.md), and [P3-R2 evidence contract](architecture-hard-reset/09-p3-r2-runtime-evidence-contract.md) are one decision set. Current source and tests remain authoritative until each phase lands.

## How To Read The Records

- `chat-skill-routing` and `node-first-skill-engine` are delivered design records. Their proposed implementation steps are historical; use the code locations above for current contracts. For `node-first-skill-engine`, the most recent implementation completion is detailed in [05-contract-hardening-and-authoring-ux.md](node-first-skill-engine/05-contract-hardening-and-authoring-ux.md), which covers reads enforcement, skill UX refinements, and cross-service error handling.
- `settings-skill-redesign` is the current product-design record for the settings experience. Its initial phases have been delivered; remaining work must be derived from an observed code or test gap.
- The former `skill-authoring` plan was archived and has now been deleted; its UI scope lives in `settings-skill-redesign`, and its storage/CRUD scope in `node-first-skill-engine`. Do not recreate a second editor, schema, or runtime from it.
- `copilot-shared-core` and `agent-skill-standard` are delivered historical records; use their current headers and code authority for the implemented boundary. `agent-platform-redesign` remains the delivered D1–D7 record, but its future R6 policy is superseded by Architecture Hard Reset. New implementation work follows the hard-reset phase gates, not the historical coexistence sequence.
- `harness-workflow-compilation` is a delivered historical record (that workstream's P1–P4, not Architecture Hard Reset P1–P4); its future consolidation is superseded by Architecture Hard Reset per its own file headers.
- `test-audit/ledger.md` is a one-off 2026-07-26 test-audit snapshot, not a general backlog. All fourteen adjudicated entries are closed; ledger item 15's pinned-path tool-budget regression was completed on 2026-08-08.
